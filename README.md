# Warbands

A pixel-art medieval fantasy auto battler for the browser. Build a warband, merge three copies of a unit to level it up, and fight enemy warbands. A run ends at 10 wins or after losing all 5 lives.

**This is an early playtest version.** Units still use placeholder icons, and numbers and units change often. Feedback is welcome.

## Play
Open `index.html` in a browser. The first launch starts with a short tutorial, and Play unlocks after it.
